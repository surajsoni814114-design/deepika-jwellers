DEEPIKA JWELLERS - वेबसाइट शुरुआती पैकेज

फाइल: index.html

महत्वपूर्ण:
- यह मोबाइल-फ्रेंडली वेबसाइट का शुरुआती फ्रंटएंड है।
- इसमें एक सार्वजनिक तृतीय-पक्ष API endpoint का प्रयोग उदाहरण के रूप में किया गया है: https://api.dharun.dev/v1/bullion
- इसे असली दुकान/व्यावसायिक उपयोग में प्रकाशित करने से पहले API के वर्तमान JSON schema, उपलब्धता, लाइसेंस/री-यूज़ शर्तें और IBJA attribution की पुष्टि करें।
- IBJA की आधिकारिक API व्यावसायिक/लेन-देन आधारित उपयोग के लिए सीधे IBJA से लेना उचित है।
- यह वेबसाइट अभी प्रकाशित नहीं है और इसमें कोई होस्टिंग/डोमेन शामिल नहीं है।
- वेबसाइट IBJA benchmark rates दिखाने के लिए है; GST, मेकिंग चार्ज और दुकान का मार्जिन शामिल नहीं।
- तृतीय-पक्ष API बदलने/बंद होने पर डेटा लोड नहीं होगा; वेबसाइट गलत/पुराना रेट नया बताकर नहीं दिखाती।

लोकल टेस्ट:
index.html को ब्राउज़र में खोलें। कुछ ब्राउज़र में API/CORS के कारण लोकल फाइल से fetch ब्लॉक हो सकता है; इसे HTTPS hosting पर टेस्ट करें।
